
# Juego del Ahorcado en Java

Este proyecto implementa el clásico juego del ahorcado utilizando Java.  
El jugador debe adivinar la palabra secreta introduciendo letras, con un número limitado de intentos.

## Características
- Palabra secreta definida en el código.
- Control de intentos máximos.
- Visualización de progreso con guiones bajos.
- Mensajes de victoria o derrota.
## Herramientas utilizadas
1. Clase Scanner
2. Declaracion y asignaciones
3. Arreglos
4. Estructura de control: Iterativa (Bucle)
5. Clase string y sus métodos valueOf, charAt y length()
6. Clase character y su método toLowerCase
7. Estructura de control: condicional
## Cómo ejecutar
1. Compila el proyecto desde la carpeta `src`.
2. Ejecuta la clase principal `juegosAhorcado`.
3. Ingresa letras en la consola para intentar adivinar la palabra.
